# HellBrowser

HellBrowser is an Android WebView-based browser built for Android Auto head units, designed for use while parked or by passengers.

## App Details

| | |
|---|---|
| **App Name** | HellBrowser |
| **Package / Application ID** | com.kododake.hellbrowser |
| **Version** | 2.2 (versionCode 8) |
| **Minimum Android Version** | Android 15 (API 35) |
| **Target Android Version** | Android 15 (API 37) |
| **License** | GPLv3 |
| **Platform** | Android Auto head unit displays |

## Features

- Native UI built for car displays, not a stretched phone layout
- Fullscreen video playback (Widevine L3 DRM support)
- Light theme and true-black AMOLED dark theme
- Optional page-level dark mode for supported websites
- Home page or a start page dashboard with up to six quick-link shortcuts
- Multiple tabs with an in-app tab manager
- Restore previous tab session on launch
- Resume the last visited page on launch
- Optional persistent, compact URL bar
- Configurable floating quick action button (position and behavior)
- Locally cached site icons for quick links
- Adjustable global UI and page display scale
- Desktop / mobile rendering toggle
- Bookmark dashboard for quick access to saved sites

## Requirements

- Android 15 or later
- Android Auto "Unknown sources" enabled (via hidden Developer Settings) to sideload the APK

## Safety Notice

HellBrowser is intended for use only while parked or by passengers. Do not view or interact with this app while driving.
